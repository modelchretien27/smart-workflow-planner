Alertes e-mail

Les alertes utilisent EmailJS pour envoyer un e-mail (professionnel ou personnel) directement depuis le navigateur, sans backend supplémentaire. Renseigne tes identifiants EmailJS (gratuits sur emailjs.com) pour activer l'envoi réel. Sans configuration, les alertes restent visibles dans le centre de notifications interne.

Pour un envoi 100% automatique (sans que quelqu'un ait la page ouverte), il faudra brancher un job planifié côté backend qui appelle un endpoint de vérification quotidienne. La logique de calcul des statuts est déjà prête côté client pour ça — voir le commentaire "BACKEND REQUIS" dans le code source.
